SISTEM PEMARKAHAN KAFA - PROTOTAIP 1
1. Ekstrak fail ZIP.
2. Buka index.html dalam Google Chrome atau Microsoft Edge.
3. Pilih murid dan masukkan markah. Gunakan TH bagi tidak hadir.
4. Klik Simpan Markah. Data disimpan dalam localStorage pelayar/peranti.
5. Pergi ke Slip Keputusan untuk cetak individu atau semua murid.
6. Pada dialog cetak pilih Save as PDF, kertas A4, skala 100% dan margin none.

PERHATIAN: Versi ini prototaip offline. Tiada akaun pengguna atau sync Supabase. Data disimpan dalam pelayar sahaja. Jangan kosongkan data laman sebelum sandaran. Susunan asas slip mengikuti helaian SLIP, tetapi kesetaraan visual piksel-ke-piksel dengan Excel belum disahkan; sila semak cetakan fizikal. Formula peratus menggunakan jumlah / 700; gred A >=80, B >=60, C >=40, D >=20, E selebihnya. Kedudukan berdasarkan jumlah, kedudukan seri dikongsi.
